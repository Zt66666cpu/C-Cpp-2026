## D-002：采用“战术护栏 + Alpha-Beta 算路 + 可训练参数/纯 C 轻量网络推理”三层混合架构

- 状态：已采纳
- 日期：2026-10-21，确认并细化于 2026-11-19
- 决策：不写死复杂的 `if-else` 走子规则表，采用三层混合路线：
  1. **第一层（战术护栏 / 硬规则辅助）**：复用规则与禁手模块，只用确定性代码处理合法落子、禁手排除、一步成五必胜、对方四子威胁必防以及邻域候选点收缩。
  2. **第二层（动态推演引擎）**：以 Minimax + Alpha-Beta 剪枝为核心算路框架（M2），逐步加入迭代加深、着法排序、计时控制与置换表（M3）。
  3. **第三层（智能估值与策略引导）**：从 M2 起将局面估值与着法打分设计为可插拔的参数化特征接口（$\mathbf{w}^\top \mathbf{x}$），先用初始权重打通完整对弈闭环；后续通过自对弈或 RTX 4070 训练参数/小型 Policy-Value 神经网络，将权重导出为纯 C 数组或二进制文件，在 C11 中手写矩阵/网络前向推理层完成本地离线推理（M4/M5）。
- 原因：兼顾课程底线稳定性与真正的智能性；纯 C 手写轻量网络前向推理可完全避免 LibTorch/ONNX 等跨平台 C++ 依赖，且在课程答辩中极具解释价值与亮眼度。
