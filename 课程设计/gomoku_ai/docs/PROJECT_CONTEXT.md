# 项目背景与长期约束

## 用户情况

- 正在学习 C/C++ 程序设计，主体课程内容应亲自完成。
- 对结构体、指针和递归有初步掌握。
- 尚未系统学习树、Minimax、Alpha-Beta、哈希表和神经网络。
- 可用设备包括当前 macOS 开发电脑，以及一台带 RTX 4070 的 Windows 笔记本。
- 没有固定每周投入时间，适合按可验证的小里程碑推进。

## 最终目标

交付一个能在本地独立运行、严格遵守规则、可稳定对弈并完整下完一盘棋的五子棋程序。这是唯一硬性目标。估值、Minimax 和 Alpha-Beta 是不想深入探索时的推荐保底方案；老师鼓励自主探索，因此可以在此基础上选择搜索强化或神经网络路线。

## 已确认边界

- 棋盘按国际通用五子棋采用 15×15。
- 黑方先行，具体开局协议仍待确认。
- 有禁手；是否只包含黑方长连、双四、双三，还是采用完整连珠开局与禁手规则，仍待确认。
- 每步最多 60 秒，无总时限。
- 最终提交的是完整、可运行程序。
- 老师唯一硬性目标是程序能够完成一盘五子棋对战。
- 老师鼓励超越基础算法的探索，不以三个基础算法作为强制及格线。
- 可用 C 或 C++，使用 CLion 当前学习环境。
- 允许第三方库，也允许查询和参考开源代码。
- 正式对局在本地运行；RTX 4070 可用于训练。
- 允许在训练神经网络阶段使用外部 AI 或 API，但最终运行不能依赖外部服务。
- 制作和调试过程必须在 GitHub 仓库中可见，建议直接复用当前 C++ 课程仓库。
- 每个细小但可展示的版本都可以提交，用来体现迭代过程。
- 课程仓库为 `Zt66666cpu/C-Cpp-2026`，本项目位于 `课程设计/gomoku_ai/`。

## 实施原则

1. 先规则正确，再谈棋力。
2. 先完成可完整对弈的硬性目标，再增加高级算法。
3. 每个阶段都保留一个可运行版本。
4. 优先选择用户能理解、调试和答辩时能解释的技术。
5. 参考开源实现时只吸收经过理解的部分，并记录来源、许可证和修改内容。
6. 每个独立、可验证的增量都通过 Git 提交并在远程可见。

## 风险

- 禁手规则尤其“双三”和递归判定复杂，容易成为隐藏 bug。
- 初学者同时学习搜索、神经网络和工程化会显著增加完不成主线的风险。
- 没有官方评测程序，因此必须自建规则测试和自动对弈基准。
- 训练神经网络需要数据、训练流程、推理集成和稳定测试，项目成本远高于基础 Alpha-Beta。
