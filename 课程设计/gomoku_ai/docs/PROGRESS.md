## 已知风险

- 双三判定和递归威胁识别复杂，可能产生隐蔽错误。
- 没有官方擂台程序，棋力比较需要自建合理基准。
- 神经网络路线容易消耗大量时间，不应阻塞可完整对弈版本。
- 用户时间投入不固定，因此每个里程碑必须可独立形成可运行成果。
- 课程仓库中同时存在其他章节作业的未提交改动，本项目提交时必须限定暂存路径。
- macOS 当前没有全局 CMake，命令行构建依赖安装 CMake；CLion 内置 CMake 已可用。
- 最终 Windows 演示环境的编译器仍待确认。
- 当前双三和双四采用基础威胁枚举，尚未覆盖完整连珠的全部递归例外。
